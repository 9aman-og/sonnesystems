lyfe
Available now

Personal workspace

Keep tasks, notes, projects, and learning in one place.

Lyfe is a personal workspace for planning today, tracking work, keeping notes and documents, saving useful material, and managing learning. Aero is built into the same workspace.

Guest data stays in your browser. Optional sign-in adds private sync across devices. Lyfe can be installed as an app and used offline.

lyfe connect
Preview

Social and collaboration prototype

Explore how Lyfe could support shared work.

The preview includes profiles, sample posts, opportunities, conversations, channels, shared pages, project boards, calendars, and saved items.

It runs locally with fictional sample data. Nothing is published or sent to a real person. Approved profile details can move between Lyfe and Connect, while private tasks, notes, Gmail, and planning stay in Lyfe.

Aero
Available in Lyfe

Assistant inside Lyfe

Turn plain language into changes you can review.

Aero can use the parts of Lyfe you choose, answer questions, and prepare tasks, notes, projects, and other changes. You see the proposed change before anything is saved.

You can inspect or remove Aero's memory. Built-in tools work offline, a local model can be connected through Ollama, and an optional cloud route receives only the current prompt.

Aero is part of Lyfe. EOS and EOS-F1 are separate research projects.

EOS-F1
Research ongoing

Small-model research

A model that remains unavailable when its checks fail.

EOS-F1 tests whether a small model can show evidence for an answer, refuse when evidence is missing, and remain unavailable when it fails a fixed evaluation.

The current 0.6B model passed 7 of 12 checks, so it has not been released. A dense baseline improved on narrow measures, while a sparse-specialist version performed worse and was stopped.
