Spiking networks

Did the spiking hybrid reduce estimated work?

On one grayscale dataset, yes. On a colour-image dataset, no.

We compared a CA-LIF spiking hybrid with a matched conventional network. At low timestep counts on Fashion-MNIST, the hybrid used fewer estimated operations. On CIFAR-10, preparing the colour input removed that advantage.

Limit

We estimated operations in software. We did not measure energy or speed on neuromorphic hardware, so this is not a general efficiency claim.

Continual learning

When should a learning system change its structure?

EOS tests whether new information requires reuse, repair, more evidence, or new structure.

Project SOL was the earlier program. EOS is the current system. It makes a prediction before learning from each new observation, then compares several responses: reuse existing knowledge, combine it, repair it, wait, or propose something new. A proposed change remains isolated until it passes a recorded test.

Limit

This is a controlled method for testing structural change. It does not prove general intelligence, unlimited lifelong learning, or lower energy use.

EOS-F1

Why is EOS-F1 not available?

The current 0.6B model passed 7 of 12 fixed checks, so it has not been released.

EOS-F1 tests whether a small model can show evidence for an answer, refuse when evidence is missing, and remain unavailable when its evaluation fails. The training and reload process worked, but the model did not pass enough checks to generate answers.

A separate dense baseline improved on narrow language measures. A matched sparse-specialist version performed worse, even under an idealized test, so we stopped that approach.

Limit

EOS-F1 is not ready for public use. The current work does not establish broad reasoning, hardware efficiency, autonomous research, or general intelligence.

Image robustness

When can brightness change without changing the output?

Only when the brightness change preserves the order of image values.

The method represents an image by the order of its values. If a brightness change preserves that order, the model output can remain exactly the same.

Limit

The guarantee covers only that defined class of brightness change. Tied values, flat image regions, and guarantees in ordinary pixel space remain unresolved.
